# ATLANTIK RUN

Portal pelaporan dan leaderboard ATLANTIK RUN 2026.

## Stack awal

- Next.js 16
- React 19
- TypeScript
- App Router
- ESLint
- Vercel

## Menjalankan project

Pastikan Node.js minimal versi 20.9.

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`.

## Build production

```bash
npm run build
```

## Tahap berikutnya

1. Hubungkan PostgreSQL.
2. Buat tabel `users`.
3. Buat tabel `run_activities`.
4. Import data user.
5. Implementasi login NIP dan session.
